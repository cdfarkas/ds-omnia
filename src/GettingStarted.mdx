## <Localized en="2. Import the styles" fr="2. Importer les styles" />

```tsx
import '@cfarkas/omnia/styles.css';
```

<Localized
  en={
    <p>
      Import it once, at the app entry, <strong>before</strong> any of your own{' '}
      <code>@layer overrides</code> rules. The stylesheet opens with the cascade-layer
      order, ending in <code>overrides</code>; if your CSS names that layer first, the
      order flips and your overrides lose.
    </p>
  }
  fr={
    <p>
      Importez-la une seule fois, à l'entrée de l'application, <strong>avant</strong> vos
      propres règles <code>@layer overrides</code>. La feuille de style commence par
      l'ordre des couches de cascade, qui se termine par <code>overrides</code> ; si votre
      CSS nomme cette couche en premier, l'ordre s'inverse et vos surcharges perdent.
    </p>
  }
/>

## <Localized en="3. Load the fonts" fr="3. Charger les polices" />

<Localized
  en={

  fr={
    <p>

<Localized
  en={
    <p>
      To use your own faces, skip the entry and set the font variables in{' '}
      <code>@layer overrides</code>:
    </p>
  }
  fr={
    <p>
      Pour utiliser vos propres fontes, ignorez l'entrée et définissez les variables de
      police dans <code>@layer overrides</code> :
    </p>
  }
/>

```css
@layer overrides {
  :root {
    --omnia-palette-font-display: 'Your Serif', georgia, serif; /* neutral headings */
    --omnia-palette-font-sans: 'Your Sans', system-ui, sans-serif; /* body */
    --omnia-palette-font-brutalist: 'Your Heavy', system-ui, sans-serif; /* brutalist */
    --omnia-palette-font-pixel: 'Your Pixel Font', monospace; /* pixel skin */
  }
}
```

<Localized

  }
  fr={

  }

## <Localized en="4. Wrap the app" fr="4. Envelopper l'application" />

```tsx
import '@cfarkas/omnia/styles.css';
import { OmniaThemeProvider, Button } from '@cfarkas/omnia';

export const App = () => (
  <OmniaThemeProvider>
    <Button>Hello</Button>
  </OmniaThemeProvider>
);
```

      page.
