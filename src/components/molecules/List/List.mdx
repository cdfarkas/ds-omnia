# List

<Localized
  en={
    <>
      <p>
        Use <strong>List</strong> for a semantic bulleted or numbered list of short,
        related items — features, steps, links. Write each entry as a{' '}
        <code>{'<List.Item>'}</code> child rather than passing an array.
      </p>
      <ul>
        <li>
          <strong>Compose it with List.Item.</strong> Each entry is its own{' '}
          <code>List.Item</code> child, so you write the items as markup instead of
          handing the list an array of data.
        </li>
        <li>
          <strong>
            Bullets or numbers with <code>as</code>.
          </strong>{' '}
          A list is bulleted by default; set <code>as</code> to make it numbered when the
          order of the items matters, such as the steps of a procedure.
        </li>
        <li>
          <strong>Items hold anything.</strong> An item can carry plain text, links,
          badges or a whole nested List, which indents under its parent item.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colour, font and spacing come from
          tokens, so List follows the light/dark theme and the neutral/pixel skin with no
          CSS changes.
        </li>
      </ul>
    </>
  }
  fr={
    <>
      <p>

        d'éléments courts et liés — fonctionnalités, étapes, liens. Écrivez chaque entrée
        comme un enfant <code>{'<List.Item>'}</code> plutôt que de passer un tableau.
      </p>
      <ul>
        <li>
          <strong>Composez-la avec List.Item.</strong> Chaque entrée est son propre enfant{' '}

          fournir à la liste un tableau de données.
        </li>
        <li>
          <strong>
            Puces ou numéros avec <code>as</code>.
          </strong>{' '}
          Une liste est à puces par défaut ; réglez <code>as</code> pour la numéroter
          quand l'ordre des éléments compte, comme les étapes d'une procédure.
        </li>
        <li>
          <strong>Les éléments contiennent n'importe quoi.</strong> Un élément peut porter

        </li>

          <strong>Elle s'adapte toute seule.</strong> La couleur, la police et
          l'espacement viennent des jetons : List suit le thème clair/sombre et

        </li>
      </ul>
