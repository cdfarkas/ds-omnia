# Stat

<Localized
  en={
    <>
      <p>
        Use <strong>Stat</strong> to put figures forward with their captions — the
        headline numbers of a landing or portfolio page, such as "30+ components". For a
        list of labelled facts about one thing, use DescriptionList instead.
      </p>
      <ul>
        <li>
          <strong>Build it from parts.</strong> <code>Stat</code> holds one{' '}
          <code>Stat.Item</code> per figure, even when there is only one. In each item,
          write a <code>Stat.Label</code> for the caption, a <code>Stat.Value</code> for
          the figure and, if needed, a <code>Stat.Hint</code> for a supporting line such
          as a change or a date range.
        </li>
        <li>
          <strong>Write the label first; the figure shows first.</strong> The label comes
          first in your code because a caption must precede what it describes. On screen
          the figure is drawn above it, since a big number reads best on top.
        </li>
        <li>
          <strong>Screen readers hear a real pair.</strong> It renders a native
          description list, so the caption is announced as the term and the figure as its
          description ("components, 30+"). Swapping their visual order does not change
          that meaning.
        </li>
        <li>
          <strong>The figure takes any content.</strong> A number, a price, a ratio like
          "100 % / 36 %" — format it the way you want it read. Long values wrap instead of
          overflowing.
        </li>
        <li>
          <strong>One list, however many figures.</strong> Screen readers hear a single
          list whether it holds one figure or ten. Several figures sit in a row that wraps
          to fewer columns on narrow screens; set <code>orientation="vertical"</code> to
          keep them in one column.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colour and fonts come from tokens, so it
          follows the light/dark theme and the neutral/pixel skin with no CSS changes.
        </li>
      </ul>
    </>
  }
