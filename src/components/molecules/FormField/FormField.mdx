# FormField

<Localized
  en={
    <>
      <p>
        Use <strong>FormField</strong> around any form control that needs a visible label,
        a hint or an error message. It links them to the control for assistive technology,
        so you never write an <code>id</code> or <code>aria-describedby</code> by hand.
      </p>
      <ul>
        <li>
          <strong>Four parts, in the order you write them.</strong>{' '}
          <code>FormField.Label</code> names the control, <code>FormField.Control</code>{' '}
          renders it, <code>FormField.Description</code> holds the hint and{' '}
          <code>FormField.Error</code> the message. Use only the parts you need.
        </li>
        <li>
          <strong>The control receives the wiring, it does not look for it.</strong>{' '}
          <code>FormField.Control</code> calls its <code>render</code> function with the
          attributes to spread on the control and the field state. Omnia's inputs stay
          plain presentational components that know nothing about the field.
        </li>
        <li>
          <strong>Pass the invalid state to the atom yourself.</strong> Spreading the
          attributes marks the control invalid for assistive technology; the red border of
          an Omnia atom comes from its own <code>invalid</code> prop, read from the state.
        </li>
        <li>
          <strong>Any control works through the hook.</strong> Inside a field,{' '}
          <code>useFormField()</code> returns the same attributes, so a native{' '}
          <code>&lt;select&gt;</code> or a third-party control can be wired in a small
          component of its own.
        </li>
        <li>
          <strong>Your own props win when written after the spread.</strong> An{' '}
          <code>id</code> or <code>aria-describedby</code> placed after{' '}
          <code>{'{...props}'}</code> replaces the field's value; it is not merged with
          it.
        </li>
        <li>
          <strong>Required shows a star.</strong> With <code>required</code>, the label
          gains a <code>*</code> hidden from screen readers and the control gets the
          native <code>required</code> attribute, which screen readers announce.
        </li>
        <li>
          <strong>The error appears only when the field is invalid.</strong> It also stays
          hidden when it has no content, and only rendered parts are referenced by the
          control.
        </li>
      </ul>

```tsx
import { FormField, Input } from '@cdfarkas/omnia';

<FormField invalid={Boolean(error)} required>
  <FormField.Label>Email</FormField.Label>
  <FormField.Control
    render={(props, { invalid }) => <Input {...props} type="email" invalid={invalid} />}
  />
  <FormField.Description>We send the receipt to this address.</FormField.Description>
  <FormField.Error>{error}</FormField.Error>
</FormField>;
```

### <Localized en="Browser validation" fr="Validation du navigateur" />

<Localized

      <li>
        <strong>

        </strong>{' '}

### <Localized en="With a form library" fr="Avec une bibliothèque de formulaires" />

```tsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';
import { FormField, Input } from '@cdfarkas/omnia';

const schema = z.object({
  email: z.email('Enter an email address like name@example.com.'),
});

function SignUp() {
  const { register, handleSubmit, formState } = useForm({
    resolver: zodResolver(schema),
  });
  const error = formState.errors.email?.message;
  return (
    <form onSubmit={handleSubmit(console.log)} noValidate>
      <FormField invalid={Boolean(error)} required>
        <FormField.Label>Email</FormField.Label>
        <FormField.Control
          render={(props, { invalid }) => (
            <Input {...props} {...register('email')} type="email" invalid={invalid} />
          )}
        />
        <FormField.Error>{error}</FormField.Error>
      </FormField>
    </form>
  );
}
```
