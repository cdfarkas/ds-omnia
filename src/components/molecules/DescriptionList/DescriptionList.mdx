# DescriptionList

<Localized
  en={
    <>
      <p>
        Use <strong>DescriptionList</strong> to show labelled facts about one thing — a
        record's properties, a summary before submitting a form, a product's
        specifications. Each row pairs a term with its detail.
      </p>
      <ul>
        <li>
          <strong>Build it from parts.</strong> Wrap each pair in{' '}
          <code>DescriptionList.Item</code>, with one <code>DescriptionList.Term</code>{' '}
          followed by its <code>DescriptionList.Detail</code>. A term with several values
          can take more than one detail.
        </li>
        <li>
          <strong>Real list semantics.</strong> It renders a native description list, so
          screen readers announce how many items there are and which detail belongs to
          which term.
        </li>
        <li>
          <strong>It adapts to its own width.</strong> In a narrow space each term sits
          above its detail; once the list is wide enough, terms form a left column and
          details a wider right one. It follows the space it is given, not the screen
          size, so it works the same in a sidebar or a full page. It fills the width of
          its container, so inside a parent that shrinks to fit its content (a centred
          flex item, an inline-block) give it a width.
        </li>
        <li>
          <strong>Details take any content.</strong> Plain text, a badge, a link — long
          values wrap instead of overflowing.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colour, font and dividers come from
          tokens, so it follows the light/dark theme and the neutral/pixel skin with no
          CSS changes.
        </li>
      </ul>
    </>
  }
  fr={

        <li>

          quel détail appartient à quel terme.
        </li>
        <li>
          <strong>Elle s'adapte à sa propre largeur.</strong> Dans un espace étroit,

          large à droite. Elle suit l'espace qu'on lui donne, pas la taille de l'écran :
          elle se comporte de la même façon dans une barre latérale ou une page entière.

          contenu (un élément flex centré, un inline-block), donnez-lui une largeur.
