# NavBar

<Localized
  en={
    <>
      <p>
        Use <strong>NavBar</strong> for a site's or section's main links — typically in
        the page header. Put one <code>NavBar.Link</code> inside it per destination.
      </p>
      <ul>
        <li>
          <strong>A real navigation landmark.</strong> It renders a labelled{' '}
          <code>&lt;nav&gt;</code> holding a list, so screen-reader users can jump to it
          and hear how many links it has. The label defaults to "Main"; pass your own{' '}
          <code>aria-label</code> when a page has more than one NavBar.
        </li>
        <li>
          <strong>The current page is marked.</strong> Set <code>current</code> on the
          link to the page being shown: it gets a thicker underline and the body text
          colour, and screen readers announce it as the current page. On a one-page site
          with anchor links, pass <code>aria-current="location"</code> yourself instead —
          yours wins.
        </li>
        <li>
          <strong>Each link is a Link.</strong> <code>NavBar.Link</code> takes everything
          Link takes — <code>href</code>, <code>external</code> and native anchor
          attributes — and is always the standalone kind.
        </li>
        <li>
          <strong>It wraps on small screens.</strong> When the links no longer fit on one
          line they flow onto the next, down to a 320 px wide screen. There is no
          hamburger menu: keep the list short enough to read at a glance.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colours and spacing come from tokens, so
          NavBar follows the light/dark theme and the neutral/pixel skin with no CSS
          changes.
        </li>
      </ul>
    </>
  }
