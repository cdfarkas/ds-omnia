# SectionHeading

<Localized
  en={
    <>
      <p>
        Use <strong>SectionHeading</strong> for the title row of a page section or a
        panel. It pairs the title with an optional short description and with buttons that
        act on the whole section.
      </p>
      <ul>
        <li>
          <strong>Three parts, one required.</strong> Compose it from{' '}
          <code>SectionHeading.Title</code>, <code>SectionHeading.Description</code> and{' '}
          <code>SectionHeading.Actions</code>; only the title is required.
        </li>
        <li>
          <strong>You pick the heading level.</strong> The title renders a real heading,
          and its <code>level</code> comes from the page outline, so set it from where the
          section sits in the page.
        </li>
        <li>
          <strong>The description stays short.</strong> It is muted by default and meant
          for one line of context, not for body copy.
        </li>
        <li>
          <strong>Actions follow the component's own width.</strong> On a wide container
          they sit opposite the title; when the component itself is narrow they drop under
          the text, whatever the screen size. It fills the width of its parent, so place
          it in a block rather than in a box that shrinks to its content.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Every part reads tokens, so it follows
          the light/dark theme and the neutral/pixel skin with no CSS changes.
        </li>
      </ul>
    </>
  }
