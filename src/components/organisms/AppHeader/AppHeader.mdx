# AppHeader

<Localized
  en={

        <strong>
          AppHeader goes inside <code>PageTemplate.Header</code> and renders no landmark

        </strong>

        Use it for the global bar at the top of every page: the brand at the start, the

      </p>
      <ul>
        <li>
          <strong>Three opt-in parts.</strong> <code>AppHeader.Brand</code> holds your
          logo or name (put a <code>Link</code> to the home page inside),{' '}
          <code>AppHeader.Nav</code> holds a <code>NavBar</code>, and{' '}
          <code>AppHeader.Actions</code> holds the switchers and buttons.
        </li>
        <li>
          <strong>No second banner.</strong> Every part is a plain{' '}
          <code>&lt;div&gt;</code>. <code>PageTemplate.Header</code> already renders the
          page's one <code>&lt;header&gt;</code>, and <code>NavBar</code> its labelled{' '}
          <code>&lt;nav&gt;</code>, so <code>AppHeader.Nav</code> adds no extra navigation
          landmark either.
        </li>
        <li>
          <strong>Wraps, never overflows.</strong> When the row runs out of width, the
          navigation and the actions move onto their own lines, down to 320 CSS px. There
          is no collapsing mobile menu yet.
        </li>
      </ul>
