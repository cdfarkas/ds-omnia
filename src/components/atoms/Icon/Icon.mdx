# Icon

<Localized
  en={
    <>
      <p>
        The <strong>Icon</strong> atom renders one of 33 semantic glyphs (ADR 0019). It
        consumes semantic <code>var(--…)</code> tokens only and paints with{' '}
        <code>currentColor</code>, so it inherits the surrounding text colour and reskins
        across the light/dark theme axis and the neutral/pixel skin axis without any
        change to its own CSS. Both skins' SVGs are rendered and CSS shows the one
        matching the active <code>data-skin</code> — the single source of truth from{' '}
        <code>OmniaThemeProvider</code> (ADR 0017), so an icon stays in step even when a
        consumer sets <code>data-skin</code> without the React provider.
      </p>
      <p>
        Pick the drawing with <code>glyph</code> (the typed <code>IconGlyph</code> union;{' '}
        <code>name</code> is a native HTML name and is not used, ADR 0015). Use{' '}
        <code>variantStyle</code> (<code>regular</code> / <code>solid</code>, default{' '}
        <code>regular</code>) for the active/selected state, and <code>variantSize</code>{' '}
        (<code>sm</code> / <code>md</code> / <code>lg</code>) for a fixed size — with no{' '}
        <code>variantSize</code> the icon is <code>1em</code> square and follows the
        surrounding type.
      </p>
      <p>
        Accessibility follows WCAG 1.1.1. The icon is{' '}
        <strong>decorative by default</strong>(<code>aria-hidden</code>, no role) — the
        common case is an icon inside a labelled <code>Button</code> or <code>Link</code>.
        Pass <code>aria-label</code> or <code>aria-labelledby</code> to promote it to a
        named <code>role="img"</code> for standalone use. There is no <code>color</code>{' '}
        prop: colour comes from <code>currentColor</code>, overridable through{' '}
        <code>--omnia-icon-color</code>.
      </p>
    </>
  }
