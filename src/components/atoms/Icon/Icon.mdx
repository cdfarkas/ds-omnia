# Icon

<Localized
  en={
    <>
      <p>
        Use <strong>Icon</strong> to show a small symbol beside a label or inside a
        control — a search glass, a close cross, a status mark.
      </p>
      <ul>
        <li>
          <strong>Pick the drawing by name.</strong> <code>glyph</code> chooses one of 33
          named glyphs. The searchable catalogue below shows them all.
        </li>
        <li>
          <strong>It swaps with the skin.</strong> Each glyph has a neutral drawing and a
          pixel-art drawing. The icon shows the one that matches the active skin, even
          when the skin is set without the React provider.
        </li>
        <li>
          <strong>Regular or solid.</strong> <code>variantStyle</code> switches to the
          filled drawing for an active or selected state; the default is regular.
        </li>
        <li>
          <strong>It follows the text size.</strong> With no <code>variantSize</code>, the
          icon is as tall as the surrounding text. Set it for a fixed size, from{' '}
          <code>sm</code> to <code>lg</code>.
        </li>
        <li>
          <strong>Decorative unless you name it.</strong> By default screen readers skip
          it, which suits an icon inside a labelled Button or Link. Pass{' '}
          <code>aria-label</code> or <code>aria-labelledby</code> when the icon stands
          alone and must be announced as an image.
        </li>
        <li>
          <strong>It takes the text colour.</strong> There is no colour prop: the icon
          paints with the surrounding text colour, so it follows the theme on its own.
        </li>
      </ul>
    </>
  }
