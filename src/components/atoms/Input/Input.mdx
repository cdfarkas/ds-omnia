# Input

<Localized
  en={
    <>
      <p>
        Use <strong>Input</strong> for a single line of text the user types — a name, an
        email address, a search query. It is the bare field: the label, hint and error
        message go around it.
      </p>
      <ul>
        <li>
          <strong>Always give it a name.</strong> Pair every input with a{' '}
          <code>&lt;label htmlFor&gt;</code> or an <code>aria-label</code> until the
          planned wrapping field component exists. A placeholder is never a label.
        </li>
        <li>
          <strong>A native input underneath.</strong> <code>type</code> is the native
          attribute, limited to the text-like kinds such as email or password. Every other
          prop, <code>ref</code> included, reaches the native input; only{' '}
          <code>className</code> and <code>style</code> go on the visible box.
        </li>
        <li>
          <strong>Three sizes.</strong> <code>variantSize</code> sets the scale, from{' '}
          <code>sm</code> to <code>lg</code>; it is the same scale as Button. It has its
          own name, so the native <code>size</code> attribute still works.
        </li>
        <li>
          <strong>Adornments at either end.</strong> <code>startAdornment</code> and{' '}
          <code>endAdornment</code> hold an icon, a unit or a prefix inside the box. They
          are decorative: mark an icon <code>aria-hidden</code>, and repeat any unit or
          prefix in the label.
        </li>
        <li>
          <strong>An invalid look, no validation.</strong> <code>invalid</code> marks the
          field invalid for assistive technology and draws a danger border. Pair it with
          an error message in text. Invalid is a state of its own, so an input has no
          intent.
        </li>
        <li>
          <strong>States show without colour alone.</strong> Focus draws a ring around the
          whole field, and in the neutral skin the field lifts on hover and focus.
          Disabled and read-only stay flat, and a disabled field adds a dashed border.
          Movement stops under reduced motion.
        </li>
      </ul>
    </>
