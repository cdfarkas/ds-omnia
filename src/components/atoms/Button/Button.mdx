# Button

<Localized
  en={
    <>
      <p>
        Use <strong>Button</strong> for an action the user triggers — saving, submitting a
        form, opening a dialog.
      </p>
      <ul>
        <li>
          <strong>The intent carries the meaning.</strong> <code>intent</code> picks one
          of six colour intents, from primary (the default) to danger. Each intent has its
          own rest, hover and press colours.
        </li>
        <li>
          <strong>Three sizes.</strong> <code>variantSize</code> sets the scale, from{' '}
          <code>sm</code> to <code>lg</code>; the default is <code>md</code>. It is the
          same scale as Input.
        </li>
        <li>
          <strong>A busy state for slow actions.</strong> Set <code>pending</code> while
          the action runs: the button is disabled, marked busy, and screen readers hear a
          loading message. The prop has its own name because a custom prop never reuses a
          native HTML attribute name.
        </li>
        <li>
          <strong>A native button underneath.</strong> Every native{' '}
          <code>&lt;button&gt;</code> attribute passes through unchanged.{' '}
          <code>type</code> defaults to <code>button</code>, so it never submits a form by
          accident.
        </li>
        <li>
          <strong>It moves, unless motion is reduced.</strong> On hover the button lifts
          and its shadow grows; on press it collapses onto the page. Under reduced motion
          it stays still, and colour and shadow changes still mark each state.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colours come from tokens, so Button
          follows the light/dark theme and the neutral/pixel skin with no CSS changes. Its
          loading message follows the active language.
        </li>
      </ul>
    </>
  }
