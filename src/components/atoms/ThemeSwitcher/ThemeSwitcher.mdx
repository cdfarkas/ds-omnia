# Theme switcher

<Localized
  en={
    <>
      <p>
        Use <strong>Theme switcher</strong> to let someone choose between the light and
        the dark theme. It reads and sets the theme on the surrounding Omnia provider, so
        dropping one in is enough — there is nothing to wire up. It changes the theme
        only, never the skin.
      </p>
      <ul>
        <li>
          <strong>Both themes, always visible.</strong> It shows the two choices side by
          side, a sun for light and a moon for dark, with the current one filled in. One
          glance tells you which theme is active and what the other option is.
        </li>
        <li>
          <strong>Icons only, still named.</strong> The choices carry no visible text to
          stay compact, but each button has a spoken name in the active language (“Light”,
          “Dark”), so a screen reader announces it and the name never changes with the
          state.
        </li>
        <li>
          <strong>It drives the provider.</strong> Clicking a choice sets the theme for
          everything inside the provider. The switcher takes no value prop — the provider
          is the single source of truth — so the same control works whether the provider
          is controlled or uncontrolled.
        </li>
        <li>
          <strong>Named for assistive tech.</strong> The control is a labelled group
          (“Theme” / “Thème”), and the active choice is announced as pressed. A
          screen-reader user hears which theme is on and what they can switch to.
        </li>
        <li>
          <strong>Keyboard and focus.</strong> Both choices are ordinary buttons: Tab
          reaches them, Enter or Space activates, and the focused choice shows a focus
          ring.
        </li>
        <li>
          <strong>Every theme and skin.</strong> The fill, the icon and the border come
          from semantic tokens, so the switcher meets contrast in light, dark and the
          pixel skin, where it also shows the pixel-art sun and moon.
        </li>
      </ul>
    </>
