# Checkbox

<Localized
  en={
    <>
      <p>
        Use <strong>Checkbox</strong> for an option the user turns on or off in a form
        they submit, or to select rows in a list.
      </p>
      <ul>
        <li>
          <strong>It is a native checkbox.</strong> A real checkbox input sits inside a
          label, so keyboard, focus, form posting and screen-reader support stay native.
          The whole row is the click target.
        </li>
        <li>
          <strong>Always give it a name.</strong> <code>children</code> is the visible
          label. Without it, pass <code>aria-label</code> or <code>aria-labelledby</code>;
          the types do not enforce this, so check every bare checkbox.
        </li>
        <li>
          <strong>A mixed state for “select all”.</strong> <code>indeterminate</code>{' '}
          shows that only part of a group is selected. It never changes{' '}
          <code>checked</code>, which alone sets the form value. The mixed state stays
          while the prop is true, even after a click, so set it to false in your{' '}
          <code>onChange</code> when the selection changes.
        </li>
        <li>
          <strong>Three sizes.</strong> <code>variantSize</code> sets the scale, from{' '}
          <code>sm</code> to <code>lg</code>; it is the same scale as Input.
        </li>
        <li>
          <strong>An invalid look, no validation.</strong> <code>invalid</code> marks the
          box invalid for assistive technology and draws a danger border. The atom ships
          no validation or error text, so pair it with an error message in text.
        </li>
        <li>
          <strong>It works with form libraries.</strong> Every form prop, <code>ref</code>{' '}
          included, reaches the native input, so React Hook Form, <code>FormData</code>{' '}
          and React 19 actions work as on a plain checkbox. Only <code>className</code>{' '}
          and <code>style</code> go on the label wrapper.
        </li>
        <li>
          <strong>States show without colour alone.</strong> A disabled box has a dashed
          border, and focus draws a ring around the box. Hover and press nudge the box by
          one pixel, except under reduced motion.
        </li>
      </ul>
    </>
  }
