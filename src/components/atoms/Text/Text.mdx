# Text

<Localized
  en={
    <>
      <p>
        Use <strong>Text</strong> for body copy and inline text — paragraphs, and short
        runs of text set inside a line.
      </p>
      <ul>
        <li>
          <strong>
            Pick the element with <code>as</code>.
          </strong>{' '}
          <code>p</code> (the default) for a block paragraph, <code>span</code> for inline
          text inside another line.
        </li>
        <li>
          <strong>Three sizes.</strong> <code>variantSize</code> is <code>sm</code>,{' '}
          <code>md</code> (the default) or <code>lg</code> — set it to match the
          surrounding type scale.
        </li>
        <li>
          <strong>
            <code>tone</code> de-emphasises without losing contrast.
          </strong>{' '}
          <code>default</code> is the primary text colour; <code>muted</code> is softer
          but still meets WCAG contrast in every theme and skin, so it reads as a
          de-emphasis, never an accessibility loss.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colour and font come from tokens, so
          Text follows the light/dark theme and the neutral/pixel skin with no CSS
          changes. Unlike Heading it keeps the sans font in both skins, so body prose
          stays readable in the pixel skin.
        </li>
      </ul>
    </>
  }
