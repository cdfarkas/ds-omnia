# Heading

<Localized
  en={
    <>
      <p>
        Use <strong>Heading</strong> for the titles that structure a page — a page title,
        a section title, a card title.
      </p>
      <ul>
        <li>
          <strong>It renders a real heading.</strong> <code>level</code> (<code>1</code>–
          <code>6</code>) outputs the matching <code>&lt;h1&gt;</code>–
          <code>&lt;h6&gt;</code>, so the document outline and screen readers stay
          correct. Set it from the page structure, not from how big you want the text to
          look.
        </li>
        <li>
          <strong>Size is independent of the level.</strong> <code>variantSize</code>{' '}
          controls only the appearance; leave it unset and the size follows the level.
          This lets an <code>&lt;h2&gt;</code> look small where the layout needs it,
          without breaking the outline. There are six sizes, from <code>xs</code> to{' '}
          <code>2xl</code>.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colour and font come from tokens, so
          Heading follows the light/dark theme and the neutral/pixel skin with no CSS
          changes. In the pixel skin it switches to the pixel font.
        </li>
      </ul>
    </>
  }
