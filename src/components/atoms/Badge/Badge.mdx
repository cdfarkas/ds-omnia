# Badge

<Localized
  en={
    <>
      <p>
        Use <strong>Badge</strong> for a short status label set next to the item it
        describes — a state such as “Paid”, “Draft” or “Failed”.
      </p>
      <ul>
        <li>
          <strong>The intent carries the meaning.</strong> <code>intent</code> picks one
          of six colour intents, from primary to danger; the default is neutral. The
          status intents share their colours with every other component that shows a
          status.
        </li>
        <li>
          <strong>Colour is never the only signal.</strong> The badge text must state the
          status on its own, so it still reads without colour.
        </li>
        <li>
          <strong>It is not a control.</strong> A badge has no hover, press or focus
          state. Place it inside a real control when it must trigger an action.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colours come from tokens, so Badge
          follows the light/dark theme and the neutral/pixel skin with no CSS changes.
        </li>
      </ul>
    </>
  }
  fr={
    <>
      <p>

      </p>
      <ul>
        <li>

        </li>

        </li>
