# Language switcher

<Localized
  en={
    <>
      <p>
        Use <strong>Language switcher</strong> to let someone change the interface
        language between English and French. It reads and sets the language on the
        surrounding Omnia provider, so dropping one in is enough — there is nothing to
        wire up.
      </p>
      <ul>
        <li>
          <strong>Both languages, always visible.</strong> It shows the two choices side
          by side, each written in its own language (English, Français), with the current
          one filled in. One glance tells you which language is active and what the other
          option is.
        </li>
        <li>
          <strong>It drives the provider.</strong> Clicking a choice sets the language for
          everything inside the provider. The switcher takes no value prop — the provider
          is the single source of truth — so the same control works whether the provider
          is controlled or uncontrolled.
        </li>
        <li>
          <strong>Named for assistive tech.</strong> The control is a labelled group
          (“Language” / “Langue”); each choice is a button carrying its own language, and
          the active one is announced as pressed. A screen-reader user hears which
          language is on and what they can switch to.
        </li>
        <li>
          <strong>Keyboard and focus.</strong> Both choices are ordinary buttons: Tab
          reaches them, Enter or Space activates, and the focused choice shows a focus
          ring.
        </li>
        <li>
          <strong>Every theme and skin.</strong> The fill, the text and the border come
          from semantic tokens, so the switcher meets contrast in light, dark and the
          pixel skin.
        </li>
      </ul>
    </>
