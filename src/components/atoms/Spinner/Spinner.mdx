# Spinner

<Localized
  en={
    <>
      <p>
        The <strong>Spinner</strong> atom is an indeterminate loading indicator. It
        consumes semantic <code>var(--…)</code> tokens only, so it reskins across the
        light/dark theme axis and the neutral/pixel skin axis without any change to its
        own CSS. The animated ring uses <code>currentColor</code>, so it inherits the
        surrounding text colour and meets WCAG 1.4.11 (3:1 non-text contrast) wherever
        that text already passes.
      </p>
      <p>
        The root is a <code>&lt;span role="status"&gt;</code> — a polite live region —
        whose accessible name defaults to <code>t('spinner.loading')</code> ("Loading"),
        set as <code>aria-label</code>, with the same string repeated as visually hidden
        text so a screen reader announces it when the region appears. Pass{' '}
        <code>aria-label</code> to name the activity specifically (for example "Loading
        products"); it overrides the default name. Use <code>variantSize</code> (
        <code>sm</code> / <code>md</code> / <code>lg</code>, default <code>md</code>) for
        the ring size — <code>size</code> is a native HTML name, so the axis is renamed
        (ADR 0015).
      </p>
      <p>
        When the surrounding text already announces the wait (a button label, a sentence
        beside the ring), pass <code>aria-hidden</code> to make the spinner decorative and
        avoid a second announcement. There is no <code>value</code>, <code>color</code>,{' '}
        <code>delay</code>, visible label or overlay: a determinate progress indicator is
        a separate future component. The ring keeps turning under{' '}
        <code>prefers-reduced-motion</code> because loading is essential feedback — a
        frozen ring would read as a stalled process.
      </p>
    </>
  }

      </p>

      </p>

        un retour essentiel — un anneau figé laisserait croire que le processus est
        bloqué.
