# Spinner

<Localized
  en={
    <>
      <p>
        Use <strong>Spinner</strong> to show that something is loading when you cannot
        tell how long it will take.
      </p>
      <ul>
        <li>
          <strong>It announces itself.</strong> The spinner is a polite status region that
          screen readers announce as “Loading”, in the active language. Pass{' '}
          <code>aria-label</code> to name the activity, such as “Loading products”.
        </li>
        <li>
          <strong>Decorative when the text already says it.</strong> When nearby text
          already announces the wait, such as a button label, pass{' '}
          <code>aria-hidden</code> to avoid a second announcement.
        </li>
        <li>
          <strong>Three sizes.</strong> <code>variantSize</code> sets the ring size, from{' '}
          <code>sm</code> to <code>lg</code>; the default is <code>md</code>.
        </li>
        <li>
          <strong>It takes the text colour.</strong> The ring paints with the surrounding
          text colour, so it reskins on its own and keeps 3:1 contrast wherever that text
          already passes.
        </li>
        <li>
          <strong>It keeps turning.</strong> The ring still spins under reduced motion,
          because loading is essential feedback: a frozen ring would look like a stalled
          process.
        </li>
        <li>
          <strong>Indeterminate only.</strong> It has no value, colour, delay or visible
          label. A progress indicator with a known value will be a separate component.
        </li>
      </ul>
    </>
  }
  fr={

        </li>

        </li>
        <li>
          <strong>Il prend la couleur du texte.</strong> L'anneau peint avec la couleur du
          texte environnant : il s'adapte tout seul et garde un contraste de 3:1 partout
          où ce texte passe déjà.
        </li>
        <li>
          <strong>Il continue de tourner.</strong> L'anneau tourne même en mouvement
          réduit, car le chargement est un retour essentiel : un anneau figé laisserait
          croire que le processus est bloqué.
        </li>
        <li>
          <strong>Indéterminé uniquement.</strong> Il n'a ni valeur, ni couleur, ni délai,
          ni libellé visible. Un indicateur de progression avec une valeur connue sera un
          composant séparé.
        </li>
      </ul>
    </>
  }
