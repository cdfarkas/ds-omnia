# Link

<Localized
  en={
    <>
      <p>
        Use <strong>Link</strong> to take the user to another page or place — inside a
        sentence, or on a line of its own.
      </p>
      <ul>
        <li>
          <strong>Inline or standalone.</strong> <code>variant</code> sets the placement.
          An inline link takes the size and weight of the sentence around it; a standalone
          link, the default, carries its own type on its own line.
        </li>
        <li>
          <strong>Always underlined.</strong> Both variants are underlined, so a link
          stands out without relying on colour.
        </li>
        <li>
          <strong>External links say so.</strong> <code>external</code> opens the link in
          a new window with safe defaults, adds a trailing icon, and tells screen-reader
          users that it opens a new window. A <code>target</code> you pass yourself still
          wins.
        </li>
        <li>
          <strong>Deliberately minimal.</strong> <code>href</code> is required, and it
          always renders a native <code>&lt;a&gt;</code>. There is no visited style and no
          disabled state: a disabled link is not a link.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colour and type come from tokens, so
          Link follows the light/dark theme and the neutral/pixel skin with no CSS
          changes. In the pixel skin the underline turns dashed.
        </li>
      </ul>
    </>
  }
  fr={
    <>
      <p>
        Utilisez <strong>Link</strong> pour mener l'utilisateur vers une autre page ou un
        autre endroit — dans une phrase, ou sur sa propre ligne.
      </p>
      <ul>
        <li>
          <strong>En ligne ou autonome.</strong> <code>variant</code> règle le placement.
          Un lien en ligne prend la taille et la graisse de la phrase qui l'entoure ; un
          lien autonome, par défaut, porte sa propre typographie sur sa propre ligne.
        </li>
        <li>
          <strong>Toujours souligné.</strong> Les deux variantes sont soulignées : un lien
          se distingue sans dépendre de la couleur.
        </li>
        <li>
          <strong>Un lien externe le signale.</strong> <code>external</code> ouvre le lien
          dans une nouvelle fenêtre avec des valeurs sûres, ajoute une icône en fin de
          lien, et indique aux utilisateurs de lecteurs d'écran qu'il ouvre une nouvelle
          fenêtre. Un <code>target</code> que vous fournissez vous-même l'emporte
          toujours.
        </li>
        <li>
          <strong>Volontairement minimal.</strong> <code>href</code> est requis, et le
          composant rend toujours un <code>&lt;a&gt;</code> natif. Il n'y a ni style de
          lien visité, ni état désactivé : un lien désactivé n'est pas un lien.
        </li>
        <li>
          <strong>Il s'adapte tout seul.</strong> La couleur et la typographie viennent
          des jetons : Link suit le thème clair/sombre et l'habillage neutre/pixel sans
          retoucher son CSS. Dans l'habillage pixel, le soulignement passe en tirets.
        </li>
      </ul>
    </>
