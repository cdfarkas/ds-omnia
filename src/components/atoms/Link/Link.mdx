# Link

<Localized
  en={
    <>
      <p>
        The <strong>Link</strong> atom renders a native <code>&lt;a&gt;</code> for
        navigation. It consumes semantic <code>var(--…)</code> tokens only, so it reskins
        across the light/dark theme axis and the neutral/pixel skin axis without any
        change to its own CSS. <code>href</code> is required.
      </p>
      <p>
        Use <code>variant</code> for placement: <code>inline</code> inherits the
        surrounding text's size and weight for a link inside a paragraph;{' '}
        <code>standalone</code> (the default) carries its own type for a link on its own
        line. Both variants are underlined, so a link is distinguishable without relying
        on colour alone (WCAG 1.4.1). Underlining is the variant's job, not a separate
        prop.
      </p>
      <p>
        Set <code>external</code> for a link that opens in a new window: it adds{' '}
        <code>target="_blank"</code> and <code>rel="noopener noreferrer"</code>, a
        visually-hidden "opens in new window" label for assistive technology, and a
        decorative trailing icon (<code>aria-hidden</code>). <code>external</code> is a
        design-system prop; the native <code>target</code> stays native and passable, and
        a caller's own <code>target</code> wins (ADR 0015). There is no polymorphic{' '}
        <code>as</code> prop, no <code>visited</code> styling and no <code>disabled</code>
        : a disabled link is not a link.
      </p>
    </>
  }
