# Switch

<Localized
  en={
    <>
      <p>
        Use <strong>Switch</strong> for a setting that takes effect the moment it changes,
        like a light switch. In a form the user submits, use Checkbox instead.
      </p>
      <ul>
        <li>
          <strong>It is a native switch.</strong> A real checkbox input with the switch
          role sits inside a label, so keyboard, focus and form posting stay native. The
          whole row is the click target.
        </li>
        <li>
          <strong>On or off, never mixed.</strong> The state is the native{' '}
          <code>checked</code>, and there is no indeterminate state. When on, the thumb
          slides to the end, so its position shows the state, not the colour alone.
        </li>
        <li>
          <strong>Always give it a name.</strong> <code>children</code> is the visible
          label, placed after the track. Without it, pass <code>aria-label</code> or{' '}
          <code>aria-labelledby</code>. Keep the label stable: it names the setting, not
          its current state.
        </li>
        <li>
          <strong>Three sizes.</strong> <code>variantSize</code> sets the scale, from{' '}
          <code>sm</code> to <code>lg</code>; it is the same scale as Checkbox.
        </li>
        <li>
          <strong>An invalid look, no validation.</strong> <code>invalid</code> marks the
          switch invalid for assistive technology and draws a danger border. The atom
          ships no validation or error text, so pair it with an error message in text.
        </li>
        <li>
          <strong>It works with form libraries.</strong> Every form prop, <code>ref</code>{' '}
          included, reaches the native input, so React Hook Form and <code>FormData</code>{' '}
          work as on a plain checkbox. Only <code>className</code> and <code>style</code>{' '}
          go on the label wrapper.
        </li>
        <li>
          <strong>Lock it with disabled.</strong> <code>readOnly</code> has no effect on
          this kind of input, so use <code>disabled</code>. A disabled switch has a dashed
          border, and focus draws a ring around the track. Hover and press nudge the track
          by one pixel, except under reduced motion.
        </li>
      </ul>
    </>
