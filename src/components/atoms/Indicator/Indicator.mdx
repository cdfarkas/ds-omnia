# Indicator

<Localized
  en={
    <>
      <p>
        Use <strong>Indicator</strong> for a small status dot set inline — the “live” dot
        in a header, or a waiting, running or done dot in a status list.
      </p>
      <ul>
        <li>
          <strong>The label carries the state.</strong> <code>aria-label</code> is
          required and says the state in words, such as “Available”. The colour is never
          the only signal.
        </li>
        <li>
          <strong>The intent only tints the dot.</strong> <code>intent</code> picks one of
          six colour intents, from primary to danger; the default is neutral. A
          contrasting ring keeps the dot at 3:1 against the surface, whatever the fill.
        </li>
        <li>
          <strong>Two sizes.</strong> <code>variantSize</code> is <code>sm</code> or{' '}
          <code>md</code>; the default is <code>md</code>.
        </li>
        <li>
          <strong>A pulse for live states.</strong> <code>pulse</code> adds a pulsing halo
          for something live or running. It is emphasis only, so it stops under reduced
          motion while the dot stays fully visible.
        </li>
        <li>
          <strong>Decorative when the text already says it.</strong> When the text beside
          the dot already states the status, pass <code>aria-hidden</code> so it is not
          announced twice.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colours come from tokens, so Indicator
          follows the light/dark theme and the neutral/pixel skin with no CSS changes. In
          the pixel skin the dot turns square.
        </li>
      </ul>
    </>
  }
  fr={
    <>
      <p>

        liste d'états.
      </p>
      <ul>
        <li>
          <strong>Le libellé porte l'état.</strong> <code>aria-label</code> est
          obligatoire et énonce l'état en toutes lettres, par exemple « Disponible ». La
          couleur n'est jamais le seul signal.
        </li>
        <li>
          <strong>L'intention ne fait que teinter la pastille.</strong>{' '}
          <code>intent</code> choisit l'une des six intentions de couleur, de primary à
          danger ; la valeur par défaut est neutral. Un anneau contrasté maintient la
          pastille à 3:1 sur le fond, quelle que soit la teinte.
        </li>
        <li>
          <strong>Deux tailles.</strong> <code>variantSize</code> vaut <code>sm</code> ou{' '}
          <code>md</code> ; la valeur par défaut est <code>md</code>.
        </li>
        <li>
          <strong>Une pulsation pour les états en direct.</strong> <code>pulse</code>{' '}
          ajoute un halo pulsé pour ce qui est en direct ou en cours. C'est de l'emphase
          seulement : il s'arrête en mouvement réduit, tandis que la pastille reste
          pleinement visible.
        </li>
        <li>
          <strong>Décorative quand le texte le dit déjà.</strong> Quand le texte à côté de
          la pastille indique déjà l'état, fournissez <code>aria-hidden</code> pour qu'il
          ne soit pas annoncé deux fois.
        </li>
        <li>
          <strong>Il s'adapte tout seul.</strong> Les couleurs viennent des jetons :
          Indicator suit le thème clair/sombre et l'habillage neutre/pixel sans retoucher
          son CSS. Dans l'habillage pixel, la pastille devient carrée.
        </li>
      </ul>
