# Avatar

<Localized
  en={
    <>
      <p>
        Use <strong>Avatar</strong> to show who something belongs to — a person, a team or
        a bot — as a small round picture next to their name or content.
      </p>
      <ul>
        <li>
          <strong>Picture first, then initials, then an icon.</strong> It shows the{' '}
          <code>src</code> image; if there is none, or it fails to load, it shows{' '}
          <code>initials</code>; without them, a neutral user icon.
        </li>
        <li>
          <strong>You write the initials.</strong> <code>initials</code> is never guessed
          from the name, so names in every language come out right.
        </li>
        <li>
          <strong>
            <code>alt</code> is the name, and it is required.
          </strong>{' '}
          Screen readers announce <code>alt</code> whatever the avatar shows, picture,
          initials or icon. When the name is already written next to the avatar, pass{' '}
          <code>alt=""</code> so it is not announced twice.
        </li>
        <li>
          <strong>Five sizes.</strong> <code>variantSize</code> goes from <code>xs</code>{' '}
          to <code>xl</code>; the default is <code>md</code>. The initials grow with it.
        </li>
        <li>
          <strong>It reskins on its own.</strong> Colours come from tokens, so Avatar
          follows the light/dark theme and the neutral/pixel skin with no CSS changes. In
          the pixel skin it turns into a notched square.
        </li>
      </ul>
    </>
  }
