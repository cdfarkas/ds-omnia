# Divider

<Localized
  en={
    <>
      <p>
        The <strong>Divider</strong> atom is a horizontal rule that separates content. It
        renders a native <code>&lt;hr&gt;</code> and consumes semantic{' '}
        <code>var(--…)</code> tokens only, so it reskins across the light/dark theme axis
        and the neutral/pixel skin axis without any change to its own CSS. The line is{' '}
        <code>--omnia-color-border-default</code> at{' '}
        <code>--omnia-border-width-regular</code>, and it meets WCAG 1.4.11 (3:1 non-text
        contrast) in all four modes.
      </p>
      <p>
        Because it is a native <code>&lt;hr&gt;</code>, it is a semantic separator by
        default (implicit <code>role="separator"</code>): a screen reader announces the
        content break. When the surrounding layout already separates the content visually
        and the break carries no meaning, pass <code>role="none"</code> (or{' '}
        <code>aria-hidden</code>) to make it purely decorative and drop it from the
        accessibility tree.
      </p>
      <p>
        <code>orientation</code> (<code>'horizontal' | 'vertical'</code>, default{' '}
        <code>'horizontal'</code>) is the one custom prop. Horizontal is the native{' '}
        <code>&lt;hr&gt;</code> above; vertical renders a{' '}
        <code>&lt;div role="separator" aria-orientation="vertical"&gt;</code>, because a
        native <code>&lt;hr&gt;</code> is semantically horizontal-only. A vertical Divider
        needs a <strong>sized container</strong> to fill (a flex row with a height), where
        it stretches to the full cross-axis. There is no weight or variant axis.
      </p>
      <p>
        The Divider owns <strong>no margin</strong> — the parent layout owns the spacing
        around it (a flex <code>gap</code>, say), so the rule sits flush and the same
        Divider works at any density.
      </p>
    </>
  }

        densité.
