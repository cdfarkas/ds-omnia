# Divider

<Localized
  en={
    <>
      <p>
        Use <strong>Divider</strong> to separate two groups of content with a thin rule —
        between sections in a stack, or between items in a row.
      </p>
      <ul>
        <li>
          <strong>Horizontal or vertical.</strong> <code>orientation</code> defaults to
          horizontal, which renders a native <code>&lt;hr&gt;</code>. A vertical divider
          needs a container with a height, and stretches to fill it.
        </li>
        <li>
          <strong>Meaningful or decorative.</strong> By default it is a semantic separator
          that screen readers announce. When the break carries no meaning, pass{' '}
          <code>role="none"</code> or <code>aria-hidden</code> to make it decorative.
        </li>
        <li>
          <strong>No margin of its own.</strong> The parent layout sets the space around
          it, for example with a flex gap, so the same divider works at any density.
        </li>
        <li>
          <strong>It reskins on its own.</strong> The line colour and width come from
          tokens, so Divider follows the light/dark theme and the neutral/pixel skin with
          no CSS changes. The line keeps 3:1 contrast against the surface in every theme
          and skin.
        </li>
      </ul>
    </>
  }
  fr={
    <>
