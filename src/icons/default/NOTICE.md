  `LICENSE` and README carry no copyright line).
- **License**: Apache-2.0, full text in `LICENSE` (identical to the repo and npm copies).

  `main` at `4b85ae197f6c10c8740f2b03a0be0f0864fc18ec`.
- **Modifications**: files renamed to Omnia glyph names. SVG content is unmodified: the 3.0.2 package
  already uses `currentColor` and sets no `width`/`height`.
