# <Localized en="Responsive" fr="Responsive" />

<Localized
  en={
    <p>

    </p>
  }

    <p>
      Mobile-first, avec un jeu de points de rupture fixe et restreint, et des container

    </p>
  }

## <Localized en="The rule" fr="La règle" />

<Localized
  en={
    <ul>
      <li>Mobile-first. The base layout works at 320 CSS px.</li>
      <li>
        Viewport <code>@media</code> uses only <code>30em</code>, <code>48em</code>,{' '}
        <code>64em</code> and <code>80em</code>, in range notation —{' '}
        <code>(width &gt;= 48em)</code>. Stylelint rejects any other width.
      </li>
      <li>
        A component whose layout follows its own width uses <code>@container</code> with
        local <code>rem</code> thresholds; atoms stay fluid, except Heading, whose type
        scale steps on the viewport breakpoints (ADR 0036).
      </li>
      <li>
        No responsive prop, no utility class, no hook until one is genuinely needed.
      </li>
    </ul>
  }
  fr={
    <ul>
      <li>Mobile-first. La mise en page de base fonctionne à 320 px CSS.</li>
      <li>
        Les <code>@media</code> de viewport n'utilisent que <code>30em</code>,{' '}
        <code>48em</code>, <code>64em</code> et <code>80em</code>, en notation
        d'intervalle — <code>(width &gt;= 48em)</code>. Stylelint rejette toute autre
        largeur.
      </li>
      <li>
        Un composant dont la mise en page suit sa propre largeur utilise{' '}
        <code>@container</code> avec des seuils <code>rem</code> locaux ; les atomes
        restent fluides, sauf Heading, dont l'échelle typographique suit les points de
        rupture du viewport (ADR 0036).
      </li>
      <li>
        Pas de prop responsive, pas de classe utilitaire, pas de hook tant qu'il n'est pas
        vraiment nécessaire.
      </li>
    </ul>
  }
