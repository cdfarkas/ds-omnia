## <Localized en="The two layers" fr="Les deux couches" />

<Localized
  en={
    <ul>
      <li>
        A <code>play</code> function on a story is a catalogue-worthy happy-path
        interaction, shown in the docs.
      </li>
      <li>
        <code>*.test.tsx</code> holds edge cases on composed stories (
        <code>composeStories</code>), additive to the <code>play</code>.
      </li>
      <li>
        <code>*.test.ts</code> holds pure logic, with no rendering.
      </li>
      <li>Accessibility runs inside the same runner — see the Accessibility page.</li>
    </ul>
  }
  fr={
    <ul>
      <li>
        Une fonction <code>play</code> sur une story est une interaction heureuse digne du
        catalogue, montrée dans la doc.
      </li>
      <li>
        <code>*.test.tsx</code> porte les cas limites sur des stories composées (
        <code>composeStories</code>), en complément du <code>play</code>.
      </li>
      <li>
        <code>*.test.ts</code> porte la logique pure, sans rendu.
      </li>
      <li>L'accessibilité tourne dans le même runner — voir la page Accessibilité.</li>
    </ul>
  }
/>

## <Localized en="The five gates" fr="Les cinq garde-fous" />

<Localized
  en={
    <ul>
      <li>
        <code>pnpm lint</code> — ESLint + Prettier + stylelint, including the
        no-raw-colour rule.
      </li>
      <li>
        <code>pnpm typecheck</code> — full <code>tsc --noEmit</code>, including the
        prop-name check.
      </li>
      <li>
        <code>pnpm test</code> — unit + interaction + a11y, one runner; every story runs
        in all six theme × skin modes.
      </li>
      <li>
        <code>pnpm build-storybook</code> — the catalogue builds.
      </li>
      <li>
        Agent visual validation — <code>pnpm visual-check</code> screenshots every state
        in all six theme × skin modes; the agent reads the images and records a verdict.
      </li>
    </ul>
  }
  fr={
    <ul>
      <li>
        <code>pnpm lint</code> — ESLint + Prettier + stylelint, dont la règle
        anti-couleur-brute.
      </li>
      <li>
        <code>pnpm typecheck</code> — <code>tsc --noEmit</code> complet, dont la
        vérification des noms de props.
      </li>
      <li>
        <code>pnpm test</code> — unitaires + interaction + a11y, un seul runner ; chaque
        story tourne dans les six modes thème × habillage.
      </li>
      <li>
        <code>pnpm build-storybook</code> — le catalogue se construit.
      </li>
      <li>
        Validation visuelle par l'agent — <code>pnpm visual-check</code> capture chaque
        état dans les six modes thème × habillage ; l'agent lit les images et consigne un
        verdict.
      </li>
    </ul>
  }
/>
