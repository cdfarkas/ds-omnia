## <Localized en="The rule" fr="La règle" />

<Localized
  en={
    <ul>
      <li>
        Components consume semantic <code>var(--omnia-…)</code> tokens only. No raw{' '}
        <code>hex</code>, <code>rgb()</code> or <code>hsl()</code> may appear in a{' '}
        <code>*.module.css</code> — a stylelint rule is the build gate.
      </li>
      <li>
        Tokens live in one two-tier file, <code>src/styles/tokens.css</code>: a primitive{' '}
        <code>--omnia-palette-*</code> layer (raw, fixed) and a semantic{' '}
        <code>--omnia-color-* / --omnia-radius-* / --omnia-shadow-*</code> layer that
        aliases it. Themes and skins reassign <strong>only</strong> the semantic layer.
      </li>
      <li>
        Two independent axes — a light/dark <strong>theme</strong> and a neutral/pixel{' '}
        <strong>skin</strong> — driven by <code>OmniaThemeProvider</code>. Two axes, not
        four hand-built themes.
      </li>
      <li>
        Every Omnia custom property carries the <code>--omnia-</code> prefix, so it never
        collides with a consuming app's own variables.
      </li>
      <li>
        Each status is a pair — a fill and its{' '}
        <code>--omnia-color-text-on-&lt;status&gt;</code> text colour. <code>danger</code>{' '}
        is the error status.
      </li>
    </ul>
  }
  fr={
    <ul>
      <li>
        Les composants ne consomment que des jetons sémantiques{' '}
        <code>var(--omnia-…)</code>. Aucun <code>hex</code>, <code>rgb()</code> ou{' '}
        <code>hsl()</code> brut dans un <code>*.module.css</code> — une règle stylelint
        sert de garde-fou au build.
      </li>
      <li>
        Les jetons tiennent dans un seul fichier à deux niveaux,{' '}
        <code>src/styles/tokens.css</code> : une couche primitive{' '}
        <code>--omnia-palette-*</code> (brute, figée) et une couche sémantique{' '}
        <code>--omnia-color-* / --omnia-radius-* / --omnia-shadow-*</code> qui l'aliase.
        Les thèmes et habillages ne réassignent <strong>que</strong> la couche sémantique.
      </li>
      <li>
        Deux axes indépendants — un <strong>thème</strong> clair/sombre et un{' '}
        <strong>habillage</strong> neutre/pixel — pilotés par{' '}
        <code>OmniaThemeProvider</code>. Deux axes, pas quatre thèmes écrits à la main.
      </li>
      <li>
        Chaque propriété personnalisée Omnia porte le préfixe <code>--omnia-</code> : elle
        n'entre jamais en collision avec les variables de l'application hôte.
      </li>
      <li>
        Chaque statut est une paire — un fond et sa couleur de texte{' '}
        <code>--omnia-color-text-on-&lt;statut&gt;</code>. <code>danger</code> est le
        statut d'erreur.
      </li>
    </ul>
  }
