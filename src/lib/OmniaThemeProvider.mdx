## <Localized en="Why it exists" fr="Son intérêt" />

<Localized
  en={
    <ul>
      <li>
        <strong>One mechanism for everything.</strong> The library, Storybook and a
        consuming app all theme through the same provider — no bespoke <code>data-*</code>{' '}
        wiring per app.
      </li>
      <li>
        <strong>Two axes plus locale.</strong> A light/dark <code>theme</code>, a neutral
        / pixel / brutalist <code>skin</code>, and the FR/EN <code>locale</code> — all
        read from one hook.
      </li>
      <li>
        <strong>Stateful, so toggles just work.</strong> It owns the current values and
        gives you setters, so a theme or language toggle flips them from anywhere below
        it.
      </li>
      <li>
        <strong>Collision-safe.</strong> Every custom property is <code>--omnia-</code>
        -prefixed, so it never clashes with the host app's own variables.
      </li>
    </ul>
  }
  fr={
    <ul>
      <li>
        <strong>Un seul mécanisme.</strong> La bibliothèque, Storybook et l'application
        hôte passent tous par le même provider — aucun câblage <code>data-*</code> propre
        à chaque app.
      </li>
      <li>
        <strong>Deux axes plus la langue.</strong> Un <code>theme</code> clair/sombre, un{' '}
        <code>skin</code> neutre / pixel / brutaliste, et la <code>locale</code> FR/EN —
        tout se lit depuis un seul hook.
      </li>

## <Localized en="Integration" fr="Intégration" />

<Localized
  en={
    <p>
      <strong>Uncontrolled (the common case).</strong> Wrap the app once. The provider
      owns the state and persists each choice to <code>localStorage</code>, so a reload
      restores it.
    </p>
  }
  fr={
    <p>
      <strong>Non contrôlé (cas courant).</strong> Englobez l'application une fois. Le
      provider détient l'état et persiste chaque choix dans <code>localStorage</code> : un
      rechargement le restaure.
    </p>
  }
/>

```tsx
import { OmniaThemeProvider } from '@cdfarkas/omnia';
import '@cdfarkas/omnia/styles.css';

export function App() {
  return (
    <OmniaThemeProvider defaultTheme="light" defaultSkin="default" defaultLocale="en">
      <Shell />
    </OmniaThemeProvider>
  );
}
```

```tsx
import { useTheme } from '@cdfarkas/omnia';

function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();
  return <button onClick={toggleTheme}>{theme === 'dark' ? 'Light' : 'Dark'}</button>;
}
```

<Localized
  en={
    <p>
      <strong>Static HTML</strong> (Vite, CRA): paste the blocking script — the body{' '}
      <code>getThemeInitScript()</code> returns — into <code>index.html</code>.
    </p>
  }
  fr={
    <p>
      <strong>HTML statique</strong> (Vite, CRA) : collez le script bloquant — le corps
      renvoyé par <code>getThemeInitScript()</code> — dans <code>index.html</code>.
    </p>
  }
/>

```html
<!-- index.html, inside <head>, before your app -->
<script>
  (function () {
    try {
      var s = JSON.parse(localStorage.getItem('omnia-theme') || '{}'),
        r = document.documentElement;
      r.setAttribute('data-theme', s.theme || 'light');
      r.setAttribute('data-skin', s.skin || 'default');
    } catch (e) {}
  })();
</script>
```
