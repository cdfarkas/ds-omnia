# ADR 0026 — Accessibility floor: WCAG 2.2 AA

## Status

Accepted (2026-11-03) — supersedes ADR 0006.

## Context

ADR 0006 set the floor at WCAG 2.1 AA, the EU legal baseline (EN 301 549 v3.2.1, European
Accessibility Act), and said WCAG 2.2 rules ran as `'warn'`. That was false: the axe `runOnly` list
in `.storybook/preview.tsx` stopped at `wcag21aa`, so no 2.2 rule ran at all.

The legal baseline is still 2.1 AA. On 2026-11-03 the owner decided to enforce 2.2 AA anyway.

Evidence: with the 2.2 tags added, `pnpm test` ran 29 test files and 255 tests green, with zero
violations and zero axe incomplete results across all four theme×skin modes. axe-core 4.14.0 puts
one rule under `wcag22aa` (`target-size`, SC 2.5.8 Target Size (Minimum), 24×24 CSS px) and none
under `wcag22a` yet.

## Decision

The floor is **WCAG 2.2 AA**. axe runs with `runOnly` tags `['wcag2a', 'wcag2aa', 'wcag21a',
'wcag21aa', 'wcag22a', 'wcag22aa']` and **`a11y.test: 'error'`** across **every theme and skin,
pixel included**. `wcag22a` is listed to mirror 2.1 and to pick up rules axe adds later.

Everything ADR 0006 decided carries forward unchanged: an axe *incomplete* result fails like a
violation (`.storybook/vitest.setup.ts`), and `src/styles/contrast.test.ts` asserts SC 1.4.11 (3:1)
on boundary and indicator tokens and 4.5:1 on placeholder text in all four modes. Thresholds are
never loosened and rules are never disabled to pass. There is no `'warn'` tier.

## Consequences

- A new component must meet the 24×24 px target size (SC 2.5.8) or a spacing exception; axe
  `target-size` enforces it.
- axe has no rule for 2.4.11 Focus Not Obscured, 2.5.7 Dragging Movements, 3.2.6 Consistent Help,
  3.3.7 Redundant Entry or 3.3.8 Accessible Authentication. They are reviewed by hand when a
  component could hit them: sticky or overlay content (2.4.11), drag interactions (2.5.7),
  forms and authentication (3.3.7, 3.3.8). The agent visual check is where an obscured focus shows.
- Omnia now gates above the EU legal floor, so a 2.2-only failure is a design-system choice, not a
  legal breach.
- An axe upgrade that adds 2.2 rules can fail the gate on upgrade.
