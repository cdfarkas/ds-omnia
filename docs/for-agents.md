# Omnia for agents

Orientation for an agent working on Omnia — a bilingual, themeable React 19 design system
catalogued in Storybook. Read this once, then work from the sources it points to.

## Start here

- **API index — [`components.json`](./components.json)** (generated, machine-readable). One entry
  per component exported from `src/index.ts`: props (name, type, default, required), variant axes,
  story ids, and the authored a11y/contract notes. A human-readable mirror is
  [`components.md`](./components.md). Both are generated by `pnpm docs:manifest` and gated in CI —
  never edit them by hand.
- **The contract — [`../CLAUDE.md`](../CLAUDE.md)**. The non-negotiable rules: the simplicity
  ladder, token contract, prop-naming rule, responsive rule, test convention, a11y gate, bilingual
  rule, and the five acceptance gates. Read it before changing anything.
- **Decisions — [`adr/`](./adr/)**. Every locked choice is an ADR; it changes only by a superseding
  PR, never silently. [`governance.md`](./governance.md) states that rule.
- **Detail — [`ARCHITECTURE.md`](./ARCHITECTURE.md)** (folders, compound decision tree, tokens,
  theming), [`testing.md`](./testing.md) (single runner, two layers, a11y gate),
  [`overrides.md`](./overrides.md) (the public override API).

## Conventions in one breath

- **Tokens**: components consume semantic `var(--omnia-…)` tokens only — no raw colours. Two-tier
  contract in `src/styles/tokens.css`; themes and skins reassign only the semantic layer (ADR 0003,
  0013).
- **Theming**: two axes — light/dark × default/pixel — via `OmniaThemeProvider` (ADR 0004, 0017).
- **Props**: a native HTML prop name keeps its native type; a visual axis with a native name becomes
  `variant<Axis>`; any other custom prop gets a non-native name (ADR 0015).
- **Tests**: one Storybook-driven runner — a story `play` for the happy path, `*.test.tsx` for edge
  cases, `*.test.ts` for pure logic (`docs/testing.md`).
- **A11y**: WCAG 2.1 AA across every theme and skin; an axe *incomplete* fails like a violation
  (ADR 0006).
- **Bilingual**: labels and ARIA strings go through `t()`; MDX prose through `<Localized/>`
  (ADR 0007).
- **Previewing motion**: flip the toolbar's reduced-motion control (CSS user preferences addon) to
  `reduce` to preview how motion-gated components behave under `prefers-reduced-motion` — it emulates
  both the CSS media query and `window.matchMedia`.

## Regenerate the API index

Run after any change to a component's props, variants, stories or its exports in `src/index.ts`:

```sh
pnpm docs:manifest
```

CI fails a PR whose `docs/components.json` or `docs/components.md` is out of date, so regenerate and
commit the result alongside the component change.
